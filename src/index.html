Desktop shell for Hyprland

Your desktop, in every shape.

KiiteShell is a Material 3 Expressive shell written from scratch in Rust on GPUI. Bar, dock, launcher, lock screen, widgets and an AI assistant, all colored by your wallpaper.

Three steps in.

Needs a Wayland session with Hyprland, a Vulkan driver and a stable Rust toolchain.

1

Clone and build →

git clone https://github.com/Kiite-Org/KiiteShell
cd KiiteShell
cargo build --release
2

Start it with Hyprland →

# hyprland.conf
exec-once = kiite
3

Make it yours →

kiite settings
# or edit, it reloads live
~/.config/kiite/config.json
